RealWorldGate - Financial Dashboard
This project is a modern, interactive, and visually appealing financial dashboard built with React. It was created to showcase advanced front-end development skills.

The dashboard displays a variety of simulated financial data in a clean, user-friendly interface with both light and dark themes.

Key Features
Interactive Charts: Includes a dynamic area chart with a brush/zoom feature and a bar chart to visualize data like asset values and active users.

Live Data Simulation: The ticker and main stat cards subtly update every few seconds to simulate a real-time data feed, making the dashboard feel dynamic and alive.

3D Interactive Globe: A stunning, interactive 3D globe displays fictional global asset distribution points, adding a unique "wow" factor.

Component-Based Architecture: The project is built using a clean, reusable component structure, which is a best practice in modern React development.

Responsive Design: The layout is fully responsive and designed to work on desktops, tablets, and mobile devices.


"Soft UI" & Glassmorphism Effects: The interface uses modern design trends like soft shadows and semi-transparent "glass" backgrounds for a premium feel.

Technologies Used
React: The core JavaScript library for building the user interface.

Vite: A next-generation front-end tooling for a fast development experience.

Tailwind CSS: A utility-first CSS framework for rapid and custom UI development.

Recharts: A composable charting library built on React components.

Three.js & React Three Fiber: Used to create the interactive 3D globe visualization.
